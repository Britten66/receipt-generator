Product Update

What's New: April 2026

April 13, 2026  ·  InvoicePrepper Team

This update adds a safety net for deleted invoices, fixes an annoying scroll issue in the profile settings, and ships a major internal refactor that makes the app faster to improve going forward.

What shipped

New Recently Deleted

Deleting an invoice used to be permanent and instant. Now invoices go to a trash folder first. You can restore any invoice within 30 days or permanently delete it when you are sure. Access the trash from the sidebar using the bin icon. This is a feature we heard about from users who accidentally deleted invoices and had no way to get them back.

Fix Profile settings save button always visible

The Save button in Profile and Settings was getting cut off at the bottom of the modal on smaller screens. You had to scroll down to find it, and on some devices it was easy to miss entirely. The modal now keeps the footer with the Save and Cancel buttons pinned at the bottom at all times while the fields scroll above it.

Infra App architecture refactor

The main application file was nearly 1,400 lines long. We broke it into a feature-based folder structure with separate components and hooks for auth, invoices, billing, and profile. This does not change anything visible in the app but makes it significantly faster to build new features and fix bugs going forward. Every new feature from here ships in its own folder.

What is coming next

The next release will focus on making it faster to create repeat invoices and improving the mobile experience. If you have run into something that slows you down, send feedback from inside the app and it goes directly to us.

On the roadmap

Quote mode for sending estimates before the work starts. Per-client invoice numbering. Improved Voice AI accuracy for trade and service businesses.
