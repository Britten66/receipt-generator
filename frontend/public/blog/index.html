Apr 13 2026
Improvement
Sign in and account setup
  • Accounts created with Google now see a consent step on first login. The app waits for confirmation before continuing. Blocking modal writes terms_agreed_at to the user profile via the profile Edge Function on accept.
  • Signup form simplified. Email, password, and confirm are all that is required to create an account. Consent and opt-in moved to post-login flow, applied uniformly across all signup methods.
  • Fixed an issue where accounts were not correctly identified after signing in via redirect. posthog.identify call updated to pass email alongside user ID on every SIGNED_IN event.
  • Password strength indicator now shows inline as you type. Weak, good, and strong states with colour feedback. Client-side only, no network call. Regex checks for length, number, and symbol presence.
  • Forgot password flow added. Enter your email, receive a reset link, set a new password. Supabase auth.resetPasswordForEmail with redirectTo pointing back to the app.
Apr 7 2026
New
Text AI invoice parsing (Pro)
  • Type what you did and who to bill. AI reads the description and fills in line items, quantities, and amounts automatically. Groq LLM inference via a Supabase Edge Function. Structured JSON output mapped to invoice form fields.
  • Text AI is available on Pro and Voice AI plans. Limited to 15 parses per day on Pro, unlimited on Voice AI. Rate limit enforced server-side using a monthly counter stored in the profiles table. Resets on the first of each month.
  • Text input only renders on desktop pointer devices. On mobile, voice input is the default AI method. Detected via window.matchMedia("(pointer: fine)") on mount.
  • AI section hidden entirely for free users. No input shown, no prompt visible. Conditional render gated on profile.tier at the ReceiptForm component level.
  • Upgrade prompt shown inline when a free user attempts to access AI features. onUpgradeClick prop passed down from App, opens PlansModal directly.
Mar 31 2026
New
Voice AI invoice parsing (Voice AI plan)
  • Speak your invoice out loud. Tap the microphone, describe the job, and AI fills in the invoice fields automatically. Audio recorded in the browser, uploaded to Supabase Storage audio-temp bucket, transcribed and parsed via Groq.
  • Voice input available on any device with a microphone. Works on mobile and desktop. MediaRecorder API with audio/webm encoding. Falls back to audio/mp4 on iOS Safari.
  • Voice AI is unlimited on the Voice AI plan. No daily cap. No rate limit applied server-side for voice tier. Tier check only.
  • Audio files are deleted from storage immediately after parsing. Nothing is retained. Supabase Storage delete called in the Edge Function after the parse response is returned.
  • Voice input footer stays fixed at the bottom of the form while recording is active. Position fixed, z-index layered above invoice content. Padding added to form bottom to prevent overlap.
Mar 24 2026
Improvement
Trash, themes, and export
  • Deleted invoices now go to a trash folder instead of being permanently removed. Restore any invoice within 30 days. Soft delete via deleted_at timestamp. TrashModal queries invoices where deleted_at is not null. Hard delete on confirm or after 30 days.
  • Dashboard themes added. Six colour palettes with separate light and dark selections. Your choice is saved between sessions. CSS custom property overrides applied via applyPalette. Palette key stored in localStorage and profile.
  • CSV export of all invoices. One click downloads a spreadsheet-ready file with every invoice and line item. Client-side CSV generation. Fields escaped for injection safety. BOM prepended for Excel compatibility.
  • Trash, themes, and export are available on Pro and Voice AI plans. Feature flags checked against profile.tier before rendering controls in the sidebar and topbar.
Mar 17 2026
New
Logo, mobile share, and billing portal
  • Upload your business logo. It appears on every PDF you generate, replacing the plain text business name header. Image uploaded to Supabase Storage, URL saved to profile. jsPDF addImage call pulls from the stored URL at generation time.
  • Share invoice PDF directly from your phone using the native share sheet. Send to any app, email, or messaging service without leaving InvoicePrepper. navigator.share Web Share API with a generated Blob. Falls back gracefully on unsupported browsers.
  • Manage your subscription from inside the app. View your plan, renewal date, and access the billing portal to update payment details or cancel. Stripe Customer Portal session created server-side via a Supabase Edge Function. Redirects to Stripe-hosted portal.
  • Cancelled subscriptions show a notice with the date access ends. No abrupt cutoff. cancel_at_period_end flag returned from Stripe subscription fetch, displayed in BillingModal.
  • Logo upload, mobile share, and billing management are available on Pro and Voice AI plans. Tier gate applied at the component level and enforced server-side in the profile Edge Function.
Mar 10 2026
New
Pro plan, email to client, and payment reminders
  • Pro plan now available at CAD $9 per month. Upgrade from inside the app with no external sign-up required. Stripe Checkout session created via Supabase Edge Function. Post-checkout webhook updates profile tier automatically.

Improvement
Profile, tax settings, and mobile fixes
  • Business profile now includes address, phone, email, and a short bio. All fields appear on generated PDFs. Profile fields saved to Supabase profiles table via PUT on the profile Edge Function. All inputs length-bounded server-side.

Feb 24 2026
Release
v1.0 -- Invoice creation, PDF, and status tracking
  • Create invoices with line items, quantities, unit prices, tax, due dates, and notes. Everything generates a clean PDF instantly. jsPDF with jspdf-autotable for line item rendering. All generation happens client-side, no server required.
  • Download your invoice as a PDF at any time. No watermark, no branding from us. Blob URL generated from jsPDF output. Triggered via anchor download attribute.
  • Track invoice status across Draft, Sent, Paid, and Voided. Outstanding balance updates automatically as invoices are marked paid. Status stored on the receipt row in Supabase. Revenue and outstanding calculated client-side from the receipts array on each load.
  • Filter your invoice list by status. See only what is outstanding, what has been sent, or everything at once. Client-side filter applied to the receipts array. No re-fetch on filter change.
  • Invoice numbers auto-increment per account starting from INV-000100. Each invoice gets a unique number that never repeats. Counter stored in the profiles table. Incremented atomically in a Postgres function on insert to prevent duplicates under concurrent writes.
  • All invoice data is saved to your account and accessible from any device. React frontend on Cloudflare Pages. Supabase Postgres with row-level security. Every query is scoped to the authenticated user.
